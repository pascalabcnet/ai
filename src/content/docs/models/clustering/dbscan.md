`DBSCAN` — алгоритм плотностной кластеризации.

Он не требует заранее задавать число кластеров. Вместо этого DBSCAN ищет плотные области точек и выделяет точки, которые не принадлежат ни одному кластеру, как шум.

## Идея метода

DBSCAN смотрит на соседей каждой точки.

Основные параметры:

- `eps` — радиус окрестности точки;
- `minSamples` — сколько соседей нужно, чтобы точка стала ядром кластера.

Если рядом с точкой достаточно много других точек, она считается частью плотной области. Из таких плотных областей формируются кластеры.

Точки, которые не попали ни в один кластер, считаются шумом или выбросами.

## Пример

DBSCAN хорошо подходит для кластеров сложной формы. Поэтому для учебного примера удобно использовать данные `MakeMoons`.

```pascal
uses MLABC, PlotML;

begin
  var (X, trueLabels) := Datasets.MakeMoons(
    n := 400,
    noise := 0.08,
    seed := 42);

  var scaler := new StandardScaler;
  var Xscaled := scaler.FitTransform(X);

  var model := new DBSCAN(
    eps := 0.25,
    minSamples := 5);

  var labels := model.FitPredict(Xscaled);

  Plot.Scatter(Xscaled, labels);
  Plot.Title := 'DBSCAN: кластеры сложной формы';
end.
```

## Чем отличается от KMeans

| Алгоритм | Что нужно задать | Что хорошо находит |
| --- | --- | --- |
| `KMeans` | число кластеров `k` | компактные группы вокруг центров |
| `DBSCAN` | `eps` и `minSamples` | плотные области сложной формы |

`DBSCAN` может найти шумовые точки, а `KMeans` обычно принудительно относит каждую точку к одному из кластеров.

## Ограничения DBSCAN

- чувствителен к выбору `eps`;
- плохо работает, если кластеры имеют сильно разную плотность;
- зависит от масштаба признаков;
- на больших данных может работать дольше простых методов.
