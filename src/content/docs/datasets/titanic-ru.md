`TitanicRu` — русскоязычный вариант датасета Titanic.

Файл данных:

```text
titanic_ru.csv
```

В программе датасет доступен так:

```pascal
var ds := Datasets.TitanicRu;
var df := ds.Data;
```

Датасет удобно использовать для задач классификации на табличных данных.
