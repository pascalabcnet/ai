`RussianCities` — табличный датасет с данными о российских городах.

Файл данных:

```text
russian_cities.csv
```

В программе датасет доступен так:

```pascal
var ds := Datasets.RussianCities;
var df := ds.Data;
```

Датасет можно использовать для примеров анализа табличных данных, фильтрации, сортировки и группировки.
