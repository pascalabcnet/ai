---
title: Синтетические датасеты
description: Генераторы учебных наборов данных.
---

Синтетические датасеты создаются программно. Они полезны, когда нужно быстро получить данные с заранее понятной структурой.

Например, такие датасеты удобно использовать для демонстрации классификации, регрессии и кластеризации.

Типичные примеры:

```pascal
var (X, y) := Datasets.MakeBlobs(n := 300, centers := 3, seed := 42);
```

```pascal
var (X, y) := Datasets.MakeMoons(n := 400, noise := 0.08, seed := 42);
```

Такие данные хорошо подходят для учебных графиков и проверки алгоритмов.
