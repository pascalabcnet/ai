---
title: MatrixPipeline
description: Конвейеры для уже подготовленных матриц.
---

`MatrixPipeline` используется, когда данные уже представлены матрицей признаков `X` и, для задач с учителем, вектором ответов `y`.

Он удобен, если работа с `DataFrame` уже завершена и нужно объединить преобразования матрицы и модель.
