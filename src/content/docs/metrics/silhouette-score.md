`Silhouette Score` оценивает качество кластеризации, когда истинные метки объектов неизвестны.

Метрика показывает, насколько объект ближе к своему кластеру, чем к соседним кластерам.

## Идея

Для каждого объекта считаются две величины:

- `a_i` — среднее расстояние до объектов своего кластера;
- `b_i` — минимальное среднее расстояние до объектов другого кластера.

Силуэт объекта:

$$
s_i =
\frac{b_i - a_i}{\max(a_i, b_i)}
$$

Если объект хорошо попал в свой кластер, то `a_i` маленькое, а `b_i` большое. Тогда силуэт близок к `1`.

## Интерпретация

```text
близко к 1   объект хорошо находится внутри своего кластера
около 0     объект находится между кластерами
меньше 0    объект, возможно, попал не в тот кластер
```

Итоговый `Silhouette Score` — среднее значение силуэта по всем объектам.

## Пример

```pascal
uses MLABC;

begin
  var (X, trueLabels) := Datasets.MakeBlobs(
    n := 300,
    centers := 3,
    clusterStd := 0.8,
    seed := 42);

  var model := new KMeans(
    nClusters := 3,
    seed := 42);

  var labels := model.FitPredict(X);

  Println('Silhouette:', Metrics.SilhouetteScore(X, labels):0:3);
end.
```

## Когда использовать

`Silhouette Score` полезен, когда истинных меток нет, а нужно сравнить разные варианты кластеризации.

Например, можно запустить `KMeans` с разными значениями `nClusters` и выбрать вариант с лучшим силуэтом.

## Ограничения

`Silhouette Score` основан на расстояниях, поэтому результат зависит от масштаба признаков.

Перед вычислением метрики часто стоит выполнить [масштабирование](/models/clustering/scaling/).
